# 组件拆分重构计划（a2ui / v0_9_1）

## Context（为什么做）

当前所有内置组件的渲染逻辑集中在两个巨型类里：

- [BasicCatalogRenderer.java](file:///e:/SourceCode/2026/android/a2ui/a2ui/src/main/java/org/a2ui/android/v0_9_1/BasicCatalogRenderer.java)：771 行，一个 switch 覆盖 13 种组件，同时塞入 20+ 个静态工具方法。
- [InputRenderer.java](file:///e:/SourceCode/2026/android/a2ui/a2ui/src/main/java/org/a2ui/android/v0_9_1/InputRenderer.java)：436 行，覆盖 5 种输入组件。

任何一个小改动（比如调 Text 的字号）都要在同一个文件里动刀，容易误伤其他组件，冲突和回归风险高。目标：**一个组件一个文件，彼此不直接引用，行为完全保持不变**。

## 方案要点

1. 保留 `BasicCatalogRenderer` 类名和 `render(A2uiRenderContext, String)` / `dispatchAction(...)` 签名，只把它收缩为**薄调度器 + 注册表**（`Map<String, A2uiComponentRenderer>`），因此 `A2uiView`、`A2uiRenderContext` 和文档引用都不用改。
2. 所有纯工具方法下沉到 `RenderSupport`，组件类不再引用 `BasicCatalogRenderer`。
3. 新增文件全部放在现有包 `org.a2ui.android.v0_9_1` 下，且都是包私有：**不扩大公开 API**。
4. 所有渲染器必须无状态（同一实例被多个 Surface 复用，`refreshSurfaces()` 会全量重渲染）。

## 新增文件

| 文件 | 职责 | 来源 |
| --- | --- | --- |
| `RenderSupport.java` | 静态工具：`resolve/string/bool/number/strings/bindingPath/absolutePath/primaryColor/dp/optString/requiredId/textStyle/ripple/withAlpha/placeholder/errorView` | BasicCatalogRenderer 的静态区 |
| `ComponentAction.java` | 顶层包私有类，`dispatch()` 改为调用 `context.dispatchAction(action, componentId)` | BasicCatalogRenderer 内部类 |
| `TextRenderer.java` | Text + markdown 私有方法 | `text()` |
| `ImageRenderer.java` | Image（`context.loadImage(...)` 替代 `host.getImageLoader()`） | `image()` |
| `IconRenderer.java` | Icon + `iconResource()` 私有映射表 | `icon()` |
| `MediaSupport.java` | Video/Audio 共用构建逻辑 | `video()` 公共部分 |
| `VideoRenderer.java` / `AudioPlayerRenderer.java` | 分别委托 `MediaSupport` | `video()` |
| `LayoutRenderer.java` | Row/Column：`children()`、`mainGravity/crossGravity/addSpacer`、布局算法；按 `component` 字段判断方向 | `layout()` |
| `ListRenderer.java` | deepCopy 改写为 Row/Column → `LayoutRenderer.render` → 包 ScrollView | `list()` |
| `CardRenderer.java` / `TabsRenderer.java` / `ModalRenderer.java` / `DividerRenderer.java` / `ButtonRenderer.java` | 各自组件 | 同名私有方法 |
| `InputSupport.java` | 输入类共用：`write/validate/vertical/label/controlTint/editTextTint/selectableBackground/radioGroupSetup/calendar/parseDate/formatNumber/SimpleTextWatcher` | InputRenderer 工具区 |
| `TextFieldRenderer.java` / `CheckBoxRenderer.java` / `ChoicePickerRenderer.java` / `SliderRenderer.java` / `DateTimeInputRenderer.java` | 各自输入组件，实现 `A2uiComponentRenderer` | InputRenderer 各方法 |

删除：`InputRenderer.java`（其 `renderer` 字段从未使用）。

## 必须保持的行为顺序（调度器）

1. `component == null` → `placeholder`，在 `try` 之前：不套 style、不套 styler、不套 accessibility。
2. `type` 解析也在 `try` 之前。
3. `try` 内：自定义渲染器优先 → 内置注册表 → `null` 抛 `A2uiException` → `ComponentStyleApplier.apply` → component styler → `applyAccessibility`（最后执行，会覆盖 Image/Icon 的描述）。
4. `catch` → `reportError` + `errorView("Render error: " + componentId)`；不支持类型仍单独 `reportError("不支持的组件类型: ...")`。
5. Button：先建背景 → `renderChild` → 读子组件原始 JSON 的 `style.textColor` 决定是否覆盖文字色。
6. Modal：读 `trigger.getTag()` 判 `ComponentAction`，先 dispatch 再弹窗，并覆盖 trigger 原点击监听。
7. Tabs 的 `selected` 仍是局部 `int[]`，不得提升为字段。

## 顺带清理（行为等价）

- `layout()` 末尾 `!insideList && "List".equals(...)` 分支不可达（List 传入的已是改写后的 Row/Column），删除并去掉 `insideList` 参数。
- `BasicCatalogRenderer.getHost()` 无外部调用，随重写删除。

## 修改文件

- [BasicCatalogRenderer.java](file:///e:/SourceCode/2026/android/a2ui/a2ui/src/main/java/org/a2ui/android/v0_9_1/BasicCatalogRenderer.java)：重写为注册表调度器。
- [ComponentStyleApplier.java](file:///e:/SourceCode/2026/android/a2ui/a2ui/src/main/java/org/a2ui/android/v0_9_1/ComponentStyleApplier.java)：4 处 `BasicCatalogRenderer.bool/optString` → `RenderSupport.*`，否则 style 会静默失效。

## 实施顺序（每步保持可编译）

1. 新增 `RenderSupport`，改 `ComponentStyleApplier` 的 4 处引用。
2. 新增 `ComponentAction`，抽出 `ButtonRenderer` / `ModalRenderer`，删内部类。
3. 叶子组件：Text、Image、Icon、Media/Video/Audio、Divider。
4. Layout、List。
5. Card、Tabs。
6. 5 个输入渲染器 + `InputSupport`，删 `InputRenderer`。
7. 最后重写 `BasicCatalogRenderer` 并删除残留私有方法。
